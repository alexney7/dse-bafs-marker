# DSE 企会财阅卷 Skill

`dse-bafs-marker` 是用于香港中学文凭考试（DSE）企业、会计与财务概论的 Codex Skill。它指导具备图片阅读能力的模型，根据题目和评分参考逐点批改，并提供表现预测、错题修正和教材补强建议。

**覆盖必修部分与会计选修，不覆盖商业管理选修。** 默认以教师阅卷为主，使用繁体中文；也适用于新教师学习阅卷和学生自评。

## 能做什么

- 接受照片、扫描 PDF 或文字答案，处理整套试卷、单卷、单题及少量题目。
- 将每个得分点对应到学生作答、评分要求和资料位置，区分建议分、诊断分及教师确认分。
- 核对会计帐名、借贷方向、金额、期间、结转、格式及计算步骤；错误延续与方法分依本题细则处理。
- 汇总总分并按当年规则处理选答、分部及卷间权重。
- 参考2020–2025年的等级样本，提供与所交材料范围相符的表现预测。
- 给出失分原因、必要的正确改写／计算过程，以及最多三个优先补强问题和教材位置。

## 安装

本仓库根目录就是一个完整的 Skill 文件夹，核心入口是 [SKILL.md](SKILL.md)。

将仓库克隆或下载为 `dse-bafs-marker` 文件夹，放入你的 Codex 技能目录：通常为 `~/.codex/skills/`；如已设置 `CODEX_HOME`，则使用其下的 `skills/` 目录。最终结构应为：

```text
skills/
└── dse-bafs-marker/
    ├── SKILL.md
    ├── agents/openai.yaml
    ├── references/
    └── scripts/check_library.py
```

确认 Codex 的可用技能列表出现 `dse-bafs-marker` 后，即可调用。

## 配置自己的资料库

**本仓库不包含教材、历年试卷、官方评分文件或学生答卷。** 使用者需自行准备有权使用的资料。

任选一种方式关联本地资料：

1. 在批改请求中提供资料或指定资料根目录。
2. 设置环境变量 `BAFS_MARKER_LIBRARY` 为资料根目录。
3. 将 [library.local.example.json](library.local.example.json) 复制为 `library.local.json`，把 `root` 改为你的资料根目录。

`library.local.json` 只用于本机，已列入 `.gitignore`。不要把示例路径原样当成真实路径。

[资料索引](references/library-index.json) 保存原资料库的相对目录和文件名。若要直接使用现成索引，你的目录结构需与其匹配；若结构不同，可修改索引或在请求中直接指定文件。**只修改根目录不能修复相对文件名不一致的问题。**

已有索引对应四册 Frank Wood 会计第三版教材：第一册为必修内容，第二至四册为会计内容；历史必修卷中的会计题也会按相应教材查核。

## 使用示例

上传题目、学生答案及可用的评分参考后，可以输入：

```text
使用 $dse-bafs-marker 批改这套2025年企会财会计方向答卷。
给出逐题评分、总分、整体参考等级和优先补强知识点。
```

```text
使用 $dse-bafs-marker 批改这道会计题。
给出分值、关键计算修正和本题表现预测，不推断整科等级。
```

```text
使用 $dse-bafs-marker，以新教师模式解释这些得分点为什么给分或不给分。
```

报告先给简短总览，再提供逐题证据。缺页、模糊字迹及待裁定内容会明确区分，不自动当作空白零分。没有正式评分参考时，可提供标注清楚的临时细则与诊断性建议分。

## 等级预测与使用边界

- 整套、单卷和单题的预测范围分别标明；单题表现不等于整科等级。
- 等级样本用于比较能力，不是满分答案或固定分数线；先按本题 mark scheme 评分，再比较样本。
- 单道选择题、极短题或证据不足时，只给知识点诊断，不强行预测 Level。
- 目前没有验证足以区分5*／5**的标准；没有充分依据时停留在Level5或有依据的区间。
- 本工具提供辅助阅卷建议，不是官方评核服务，也没有经过大规模阅卷准确率验证。
- 多名学生可逐份处理，本版不制作班级排名或统计报告。

## 资料核对中的关键发现

- 2021年中文评分参考缺少卷二甲；已找到同库英文备用评分页，并核对中文第1–2题数据。其他题使用前仍须逐题匹配。
- 2025年卷一甲／乙是不同版本；较早年份的“卷一乙部”则是卷内短答部分，不能混用。
- 部分年份有特别选答与分部权重，不能只把原始分相加后除以满分。
- 等级样本中的个别答案可能错误；`Level5A`或“示例二”不代表星级。

具体文件、页码与核对范围见 [资料说明](references/sources.md)、[教材索引](references/textbook-map.md) 和 [等级比较方法](references/levels.md)。

## 验证与辅助脚本

建置时已通过 Skill 格式校验、界面YAML、内部链接、登记页码范围和60个资料文件路径检查，并完成六年部分评分参考与样本对照。教材工作为目录核对与局部概念提炼，尚非四册全文逐页蒸馏；也未将六年全部样本重评。

可选的资料检查脚本只使用 Python 标准库（Python 3.9或以上）：

```bash
python scripts/check_library.py --root "/path/to/your/library"
python scripts/check_library.py --year 2025 --role sample
python scripts/check_library.py --year 2021 --role mark-scheme
```

第一条命令的 `--root` 仅对当次生效。后两条要求已配置环境变量或 `library.local.json`；也可以各自添加 `--root`。检查文件存在不等于验证内容完整。

扫描PDF需要图像阅读或渲染能力；文字提取为空不代表没有内容。具体流程见 [图片阅读说明](references/image-reading.md)。
