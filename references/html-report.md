# 學生 HTML 評估與知識點分析

## 預設交付

完成閱卷後，產出繁體中文、可離線開啟的單一 HTML 學生報告；對話只保留核心成績、重要待裁定及文件連結。使用者明確要求其他格式時從其要求。教師原評與重評差異可另在對話交代，學生報告以可行的學習反馈為主。

HTML 包含成績總覽、範圍及等級限制、分部原始分與折算、知識點圖表、逐題作答證據／理由／修正／来源、最多三項補強與教材位置。單題或少量題縮減報告，仍提供該知識點的得分及證據限制，不生成空白整科圖表。保留原印題號與重編題號的對照，避免重組卷錯配。

## 統計口徑

- 以原有評分細則的得分點為最小單位。每點有唯一ID、一個主要知識點及其上限；需要多知識標籤時只以次要文字標籤展示，不重複累加。只有细则允許合理拆分的獨立分值才拆點，不將綜合題全部分值複製到多個知識點。不宜拆分時歸入「綜合應用」並說明。
- 預設知識點得分率＝該知識點已判原始分之和／其已判上限之和；不是各題百分比的算術平均。顯示得分／上限、題數、已判覆蓋及待評上限。原始分跨卷匯總只用於診斷，不能當整科加權成績。
- 確認空白為0分並納入分母；缺頁、不可辨及待裁定保留空值，不按0處理，暫不納入已判分母。部分已判的分題拆成有依據的已判點及待判點；不能用題目已判小計除以完整上限稱確定得分率。
- 未選答、多答中不計分的題目、重複掃描頁不進總分或主要知識點圖。若教師要求另評，逐題表顯示不計入。取高分不是預設規則，必須有試卷規定或教師本次明確裁定。
- 不計班級排名，不生成沒有歷次同口徑資料的進步曲線。知識點得分率不是掌握概率；少於3題標「少量題目，證據有限」，這是展示提醒而非統計置信界限。未考到的不畫成0%。
- 額外失分原因圖僅在逐點有歸因時提供。不同原因重疊不得作可加總的餅圖；同一根本錯誤連鎖影響須用同一錯誤ID。不能由空白答卷推断是粗心、時間不足或不懂。
- 使用水平條形圖，0–100%一致刻度，並提供文字數值；不使用暗示精確能力測量的雷達圖。優先補強綜合失分額、重複問題、前置技能及證據量，不單按最低百分比排序。

## 可重用生成器

`scripts/build_report.py` 僅依賴 Python 3.9+ 標準庫，驗證得分點、分母及權重並生成無外部資源的 HTML。閱卷代理先建立JSON資料，再執行：

```text
python scripts/build_report.py assessment.json student-assessment.html
```

JSON 契約（以下只說明欄位，不能充作真實學生數據）：

- 頂層必填：`student`（姓名或代號）、`exam`、`date`、`scope`（`full`整套／`paper`單卷／`partial`局部）、`summary`、`grade_note`（範圍、依據、信心與限制）、`sections`、`points`。
- `sections`：各項有 `id`、`label`、`max`（該部納入題目的原始上限）。完整整套且權重已確認時，每項另有 `weight`（佔整科的百分點，合計100），頂層提供 `weight_source`（來源及換算公式）。未核實時完全省略weights，不猜測；full不等於一定可算整科分。
- `points`：`id`、`question`（加上卷別，包含必要新舊題號）、`section`、`topic`、`max`、`score`、`status`、`source`（文件名／PDF頁／小題）。學生報告還應提供 `evidence`、`reason`、`correction`、`basis`（AI建議分／診斷分／教師裁定及其具體範圍）。不得放入原始HTML、機密批注或不必要的個人完整路徑。
- 狀態：`scored`已評；`blank`確認空白且score為0；`pending`待裁定、`missing`缺失／不可辨、`excluded`不計入，後三者score為null。被排除題若另行評分，將診斷分寫入reason，不能進主圖及合計。
- `priorities`：0–3項，每項為 `title`、`evidence`、`textbook`、`action`、`criterion`。沒發現弱項時可空，不捏造問題。
- 欄位值均為純文字；腳本做HTML轉義。已判分不能超過上限，ID不能重複，納入點上限須等於section.max。待評存在時不顯示確定整科總分。

折算例（僅說明公式）：某模考卷二佔整科75%，卷內上限120，甲／乙／丙折算上限24／36／60，而原始上限24／50／20，則其三section.weight分別為15／22.5／37.5，section.max仍為24／50／20。不可把折算滿分當原始分母。本例不是所有考試的預設权重。

## 交付檢查

1. 逐題、知識點及分部共用同一份評分資料。驗算各部上限與得分；完整整套才按已確認權重計算總分，保留中間精度。
2. 生成本機HTML，內嵌樣式與圖表，無CDN、追蹤、遠端字體或自動發佈；特殊字元顯示為文字。支持手機寬度、表格橫向捲動及列印；圖表不用只靠顏色表達。
3. 有瀏覽器工具時打開實際檔案檢查桌面、手機及列印模式，確認圖表、中文、表格可讀。沒有工具時只聲稱已做的靜態或資料驗證，不宣稱視覺驗收。
4. 學生報告及JSON存放於本次任務輸出目錄，禁止加入Skill、GitHub倉庫或發布ZIP。Skill只攜帶通用腳本與規則。
