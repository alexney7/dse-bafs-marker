# 掃描、手寫及會計表格

本地四冊教材及多數2021–2025真題是掃描PDF。文字提取為空或只剩水印時，改為渲染閱讀，不能說內容空白或沒有題目。優先看相關頁，不把四冊全文載入。

有 Poppler 時，可用 `pdftoppm -f 3 -l 3 -r 160 -png -singlefile "input.pdf" "page-3"` 渲染指定頁。放大或裁切必須保留題號、欄名及必要相鄰行；聯絡圖只用於找位置，細小分值和手寫數字回原頁確認。

1. 先辨認試卷版本、學生編號、頁序及續頁。重複頁不重算；缺頁不同於確認空白。
2. 會計表格以欄位和行位置讀取，不用OCR的一維文字順序猜借貸。記錄帳戶標題、日期、借／貸欄、幣值單位與結餘。
3. 優先核對會改變分數的符號：括號負數、小數點、千位分隔、百分號、分數、乘除、0/6/8、1/7、劃去與改寫；核對金額到底在借方還是貸方。
4. 同一金額重複出現可輔助辨認，但不能為使借貸平衡而改寫學生數字，也不能用標準答案反推看不清的字。
5. 模糊處寫明位置、可見內容、候選讀法和受影響分值；可判部分照批。只有影響判分且無法辨認的局部才請求更清楚圖片。
6. 依題目規則處理作廢答案、超出答題區或多寫的答案；保留其位置，不默認全部有效，也不自行挑最高分版本。

引用分清檔名、PDF頁碼與印刷頁碼；教材有單元重新編頁，不能全書套固定偏移。
