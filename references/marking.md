# 企會財逐點評分

## 建立本題得分卡

先確認題幹中的指令詞、所需數量、時間、單位及表達格式。從本題細則列出每一可判點及組合上限，包括0.5分與只給整組的情況。常見細則接受列表之外合理答案；等價判斷要說明與要求的對應，而非只說「意思相近」。

已讀2020細則PDF1、2021中文PDF1、2022專輯PDF34、2023及2024專輯PDF32、2025 MS+CP PDF1的一般指引，均有回答數量及解說深度要求。題目只要求若干例子時，按適用指引處理超出的答案，不能挑最好幾點。0–3分論點的描述不是所有題通用的三分制；仍以本題分值為準。

## 必修文字與情境題

- 分開概念名稱、正確含義、題目情境及影響機制。單列術語可能只滿足識別分；要求解釋時須說明如何作用於本案。
- 例如2025卷一甲Q1(a)，評分參考PDF2同時列因素與情境例子；只寫「自然因素」「法律因素」不等於完整說明。
- 同一意思換字重複不重複計分；兩項不同但互相矛盾時，按本題要求判斷，不任意取其中有利句。
- 個人理財計算核對期數、利率的期間和複利頻率；區分計算結果與基於結果的決定。例2025卷一甲Q2(b)細則PDF2，計算和能否支付費用的判斷分開。

## 會計題判斷維度

| 題型 | 要核對的實質 | 不能採用的捷徑 |
|---|---|---|
| 原始分錄／日記簿／T字帳 | 交易性質、正確帳簿與帳名、借貸、金額、日期、結轉 | 只看左右合計相等便給全分；把帳簿名當帳戶名稱 |
| 期末調整 | 受益／賺取期間、應計預付、壞帳撇銷與準備、計提基數 | 把付款日直接當費用期間；混淆準備結餘與本期變動 |
| 財務報表 | 分類、調整流向、報表標題／期間、利潤與資本、行項及總額 | 只看最終淨利；格式不同就全題零分 |
| 存貨／折舊／變賣 | 題目指定方法、購入處置日期、殘值、成本與可變現淨值、期間比例 | 套記憶中的單一折舊率或計价法；忽略本題期間 |
| 合夥／公司 | 利潤計算和分配分開、資本／往來帳、利息、商譽、股本、股息、留存利潤 | 把合夥人分配項直接當營業費用；把未滿足確認條件的項目自動入帳 |
| 銀行調節／錯誤更正 | 銀行帳需更新項、時間差、原錯誤與正確處理差額、暫記帳 | 所有差異都入銀行帳；為配平而新增無依據項目 |
| 比率／財務分析 | 分子分母、期初期末／平均值、百分比／倍／日、比較基準、推論 | 只比數值升跌；把毛利率和加成混為一談 |
| 成本與決策 | 變動／固定、直接／間接、產量銷量、吸收與邊際、機會成本、增量收支 | 把分攤固定成本當必然可避免成本；用利潤代替邊際貢獻 |

这些是核對方向，不是額外扣分項。只有細則有給分要求才影響分數；其他問題可作學習反饋。

## 步驟、錯誤延續與數字

- 原始錯誤與後續影響建立關聯，例如「E1期末存貨算錯 → 銷貨成本 → 毛利」。診斷時只算一個根本概念問題，另記受影響題點；正式給分仍逐點依細則。
- 查本題是否允許跟進分（own figure / follow-through）、方法分、正確後續處理或獨立分。不因「避免重複扣分」就自行給跟進分，也不把一個初始錯誤後的全部作答判零。
- 允許跟進分時驗證學生確實使用自己的前項數字且方法一致；後續另有新錯仍要辨識。規則未明又影響分數時，把相關點列待裁定及合理上下界。
- 正確終值沒有過程是否可給全分，按本題要求；不要虛構未寫步驟。過程正確但結果算錯也按細則，不設定通用「扣一分」。
- 細則0.5分、複合點和最高分照原樣保留。四捨五入、幣值、百分比及月份按題目；用計算工具獨立驗算原始數字，保留中間精度，不逐步過早捨入。
- 同義帳名／可接受格式先查細則、教材及年份。直式財務報表要求不可擴張到T字帳戶。

## 新題與裁定

無本題細則時先列「臨時評分細則，待教師確認」，含得分點、分配、接受答案、方法／跟進處理和上限，再給診斷分。題幹或滿分缺失則先處理可判內容，不憑篇幅猜滿分。臨時細則的表現分析可定性描述，不能給確定等級或冒稱官方對照。

## 匯總

按學生實際選題與試卷指示決定納入題。多答規則未知時交教師裁定，不自行選最高分。分列各題原始分、各部滿分與權重、卷別折算、整體加權分；若各部權重不同，用 `Σ(該部得分/該部滿分 × 該部權重)`，再按卷間權重合成。先用當年資料證實權重，不能假設原始總分除滿分就正確。

對學生看得到的正確空白答案按細則給零；缺失／模糊／待裁定不是零。補收到頁面或教師裁定後，只重算受影響分數與預測。
